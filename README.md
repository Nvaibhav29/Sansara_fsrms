# Sansara Farms Oyster Mushroom Website

Static HTML/CSS/JS website.

Includes: home, oyster-vs-button comparison, health benefits, recipes with credited external images, and contact.

No weight, storage information, old banners, labels, or posters are included. Only the Sansara Farms logo is used.

Open `index.html` directly, use VS Code Live Server, or deploy the folder with GitHub Pages. No database is required.
